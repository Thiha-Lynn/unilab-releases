What these numbers mean

  • A person can create multiple sessions. These are not unique-user counts.
  • Files selected counts local input selections. A completed job can process several files, or no file. Exact successfully processed-file totals are not currently collected.
  • Download requests can be cancelled. *Confirmed saves are reported by supported native Android saving; browsers do not confirm that a file was saved.
  • Offline activity, opted-out activity and blocked events are absent. Automated QA is excluded.
  • No documents, filenames, passwords, participant codes, individual feedback or session identifiers are published here.
